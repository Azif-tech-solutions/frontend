# MyBiz Web — UI kit

Marketing site recreation: the surface where MyBiz introduces itself. Editorial serif display over the app's UI sans; burgundy wash behind the hero; a burgundy-950 stats band and a gradient CTA block.

| File | Section |
| --- | --- |
| `SiteHeader.jsx` | Sticky 72px nav, dual CTA, text log-in link |
| `Hero.jsx` | Eyebrow, serif headline, prompt bar, live product embed |
| `FeatureSection.jsx` | Four-up value cards + dark stats band |
| `PricingSection.jsx` | Three-tier pricing with annual/monthly toggle |
| `SiteFooter.jsx` | Gradient CTA block, five-column footer, newsletter capture |

Interactions: annual/monthly pricing toggle, editable hero prompt (→ toast), every CTA opens the trial `Dialog`.

Copy is written to the MyBiz tone described in `readme.md` → Content fundamentals. Metrics in the stats band are placeholders.
